ELEKTRON — как опубликовать отзывы на сайте (без Supabase)
================================================================

Проблема была: Supabase не работает, а без GitHub отзывы оставались
только на твоём телефоне — на сайте их не видели другие.

РЕШЕНИЕ — один раз настроить GitHub (5 минут)
---------------------------------------------

ШАГ 1 — Секрет в репозитории
  https://github.com/dm809/electron/settings/secrets/actions
  → New repository secret
  → Name: REVIEW_PIN
  → Value: 472891
  → Add secret

ШАГ 2 — GitHub token (classic)
  https://github.com/settings/tokens
  → Generate new token (classic)
  → Галочка: repo
  → Скопируй token (показывается один раз!)

ШАГ 3 — Админка сайта
  https://dmitrii-elektron.es/admin.html
  → PIN: 472891
  → «Подключить GitHub» → вставь token

ШАГ 4 — Публикация отзыва из email
  Скопируй из письма: имя, оценку, текст
  → форма «Опубликовать вручную» → Опубликовать
  → Подожди 1–2 мин → Ctrl+F5 на сайте

Или нажми ссылку «ОПУБЛИКОВАТЬ» в письме (если GitHub уже подключён).

Где хранятся отзывы на сайте
-----------------------------
  data/reviews.json в репозитории dm809/electron
  Все посетители видят их через 1–2 мин после публикации.

В модерации «Ожидают» пусто?
-----------------------------
  Это нормально без Supabase. Отзывы приходят на email —
  публикуй их вручную в форме внизу админки.
