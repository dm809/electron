═══════════════════════════════════════════════════════════════
ШАГ 0. Активировать неактивный аккаунт
═══════════════════════════════════════════════════════════════

1. Зайди: https://ads.google.com
2. Проверь уведомления (колокольчик) — часто там причина «неактивен»:
   • подтвердить email
   • добавить способ оплаты (карта)
   • пройти верификацию рекламодателя (документ / телефон)
3. Инструменты → Настройки → Платежи — привязать карту, пополнить если нужно
4. Инструменты → Настройки → Верификация рекламодателя — пройти до «Подтверждено»
5. Если аккаунт новый и «приостановлен» — напиши в поддержку через «?» → «Связаться с нами»

Без активного аккаунта и оплаты объявления не показываются.

ШАГ 1. Конверсия «Клик WhatsApp» на сайте
═══════════════════════════════════════════════════════════════

1. ads.google.com → Цели → Конверции → + Новая конверсия
2. Источник: «Сайт»
3. Категория: «Контакт» или «Потенциальный клиент»
4. Название: WhatsApp click
5. Ценность: не ставь (или 1 € для статистики)
6. Счёт: «Один» (один клик = одна конверсия)
7. Окно: 30 дней
8. Способ: «Вручную с помощью кода» → Установить самостоятельно
9. Скопируй два значения:
   • ID тега:        AW-XXXXXXXXX
   • Метка конверсии: AW-XXXXXXXXX/AbCdEfGhIj

10. Вставь в js/config.js:

    googleAdsId: 'AW-XXXXXXXXX',
    googleAdsConversion: 'AW-XXXXXXXXX/AbCdEfGhIj',

11. git push → подожди 2–5 мин → проверь сайт
12. В Google Ads → Конверции → WhatsApp click → «Проверить установку тега»
    Открой сайт и нажми любую кнопку WhatsApp — статус должен стать «Активна»

На сайте уже стоят классы gads-conversion на всех кнопках WhatsApp.
gtag подгрузится автоматически, когда заполнишь ID в config.js.

ШАГ 2. Какую кампанию создать (НЕ Leads!)
═══════════════════════════════════════════════════════════════

Рекомендация для старта: ПОИСК (Search), не Lead Gen формы Google.

• Цель: «Продажи» или «Потенциальные клиенты» → «Конверсии на сайте»
• Выбери конверсию: WhatsApp click
• Тип: Поиск (Search)
• НЕ выбирай «Формы для лидов» и «Performance Max» на первую неделю
  (PMax нужны фото/видео/тексты — подключим позже, когда наберёшь галерею)

  (или вся провинция Málaga)

═══════════════════════════════════════════════════════════════
ШАГ 4. Фото и видео на сайте (галерея)
═══════════════════════════════════════════════════════════════

Файл: js/config.js → photos.gallery

Фото — положи в images/:
  gallery-13.jpg, gallery-14.jpg …
  { type: 'image', src: 'images/gallery-13.jpg', altKey: 'gal13' },

YouTube — из ссылки youtube.com/watch?v=ABC123xyz:
  { type: 'youtube', videoId: 'ABC123xyz', altKey: 'galVideo1' },

Свой MP4 — положи в images/videos/:
  { type: 'video', src: 'images/videos/repair-1.mp4', altKey: 'galVideo2' },

После изменений: git push → сайт обновится за несколько минут.

Советы для рекламы:
• Фото: реальные платы, мультиметр, VRV блок — без размытости
• Видео: 30–60 сек, вертикальное тоже подойдёт для мобильных
• Не используй чужие фото из интернета
